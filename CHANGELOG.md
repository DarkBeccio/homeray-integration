# Changelog

## 1.0.1 - 2026-11-09

- Homeray icon inside the integration (`brand/` folder), shown by Home Assistant 2026.3 and newer.
- Network discovery: client devices added by router integrations are no longer taken for network gear; router addresses written as URLs are cleaned; a second router is drawn as an access point; only the Home Assistant host counts as a server.
- Phones are not listed as silent devices when "Ignore rechargeable batteries" is on.
- README: install from the Marketplace of Home Assistant 2026.11.

## 1.0.0 - 2026-11-09

- First release: silent devices, every battery, home network discovery for the Homeray Pro map, two sensors, options in English and Italian.
